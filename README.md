# SabaDigital — თანამედროვე Landing Page

ეს არის სრულად ადაპტური (Responsive), სემანტიკურად გამართული და თანამედროვე დიზაინის მქონე Landing Page, შექმნილი **HTML5**, **Tailwind CSS** და **Vanilla JavaScript** ტექნოლოგიებით.

## 🚀 მახასიათებლები

1. **Header / Navbar**:
   - ფიქსირებული პოზიციონირება შუშის ეფექტით (`Glassmorphism` + `backdrop-blur`).
   - სრულად ფუნქციური მობილური ჰამბურგერ მენიუ გლუვი ანიმაციით.
   - მუქი და ნათელი თემის (Dark / Light Mode) გადამრთველი ღილაკი `localStorage`-ის მხარდაჭერით.
   - გლუვი სქროლვა (Smooth Scroll) და აქტიური სექციის ავტომატური ინდიკაცია.

2. **Hero სექცია**:
   - თანამედროვე გრადიენტული ტიპოგრაფია (FiraGO & Inter ფონტები).
   - მოძრავი გრადიენტული ფონის ეფექტები (Animated Blobs).
   - მიმზიდველი Call-to-Action (CTA) ღილაკები.
   - ინტერაქტიული Glassmorphism Dashboard Preview ბარათი მოცურავე ბეჯებით.

3. **Features (შესაძლებლობები) სექცია**:
   - 3-ბარათიანი ადაპტური ბადე (Responsive Grid).
   - სტილიზებული SVG აიქონები ფერადი Glow ეფექტებით.
   - Hover მიკრო-ანიმაციები (აწევა, ჩრდილი, აიქონის ბრუნვა).

4. **About / Stats სექცია**:
   - ძირითადი მეტრიკები და სტატისტიკური მონაცემები.

5. **Contact (კონტაქტი) სექცია**:
   - თანამედროვე საკონტაქტო ბარათები (ელ-ფოსტა, ტელეფონი, მისამართი).
   - სრულად ვალიდირებული ფორმა (სახელი, ვალიდური ელ-ფოსტის Regex, ტექსტი).
   - გაგზავნის დინამიკური ლოგიკა: ღილაკის Loading Spinner, დადასტურების ბანერი და ამოტივტივებული Toast შეტყობინება.

6. **დამატებითი დეტალები**:
   - "Back to Top" მცურავი ღილაკი.
   - სუფთა და დეტალურად დაკომენტარებული კოდი.

## 💻 როგორ გავუშვათ

არ საჭიროებს დამატებით ინსტალაციას ან ბიბლიოთეკების ჩამოტვირთვას.
უბრალოდ გახსენით ფაილი `index.html` ნებისმიერ თანამედროვე ბრაუზერში (Chrome, Edge, Firefox, Safari) ორმაგი დაწკაპუნებით, ან გამოიყენეთ VS Code Live Server.
